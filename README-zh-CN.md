# 脑叶自动化
 
## 主要功能

1. 在异想体管理窗口按 `T` 以开启**开发（Exploit）**模式，该模式下 Angela 会帮你寻找合适的员工对其工作以获取 EGO 饰品
   - 再次按 `T` 以关闭
2. 在异想体管理窗口按 `X` 让 Angela 立即选派最合适的员工对该异想体进行**一次**工作（单次派工，不循环补员）
   - 管理窗口未打开时按 `X` 则执行一次练级派工
3. 按 `O` 开关**异想体管理**面板：列出设施内全部异想体，行内开关直接开发（Exploit）对应异想体，可按部门或风险等级分组，出逃中的异想体灰显不可操作
4. 按 `P` 暂停所有的自动化工作
5. 按 `V` 取消所有的自动化工作
6. **当你做出一个愚蠢的决定的时候，Angela 会羞辱你**

## 正在测试的功能

1. 自动化处理逆卡巴拉融毁事件
2. 自动化处理**黎明**和**正午**危机
   - 并不能自动处理**紫罗兰正午**，得按一下 `Alt + H` 让员工躲开先
   - 但可以自动处理**血色黄昏**，毕竟丢人考验
3. 自动化镇压出逃的异想体
   - 目前已经支持丢人蝶哥了，短期目标是自动化镇压所有的 TETH/HE 异想体
4. **避难所 ICU**：员工受伤（空闲态）即被自动送入避难所引导疗养——分诊三档，重伤绝对优先、同档就近；引导期间无敌且回复约为部门中心 2.7 倍速，血精回满即自动出院，满 28s 收手绝不触碰 30s 后的计数器清除窗口

## 自动化策略

在下列情况下，Angela 不会自动安排工作：

1. 员工的生命值/精神值低于 90%，或者并不处于**空闲**状态

2. 员工不能进行这项工作，通常是因为对该异想体工作会导致员工死亡或者异想体出逃
   - 举例来说，如果这名员工刚才对**快乐泰迪**进行过工作，那他就不会被安排对它工作（但你可以手动安排两个人，这样他们就交替了）

3. 员工并没有足够的信心在工作中活下来，目前的阈值是 99%，通常你会在 WAW/ALEPH 级异想体中碰到这个问题
